# DeepSeek API — веб-интерфейс

Минимальное локальное приложение для отправки запросов в DeepSeek API. Полный ответ API выводится в браузере как форматированный JSON.

## Запуск

1. Создайте виртуальное окружение и установите зависимости:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

2. Откройте файл `.env` и вставьте свой ключ после `DEEPSEEK_API_KEY=`.

   Никому не отправляйте ключ и не добавляйте файл `.env` в Git.

3. Запустите приложение:

   ```bash
   python app.py
   ```

4. Откройте в браузере <http://127.0.0.1:5000>.

## Как это работает

- Браузер отправляет введённый текст на локальный маршрут `POST /api/chat`.
- Python-сервер добавляет API-ключ и вызывает `POST https://api.deepseek.com/chat/completions`.
- Сервер возвращает полный JSON-ответ DeepSeek в браузер.
- JavaScript отдельно показывает текст из `choices[0].message.content`, добавляет запрос в историю с датой и временем, а полный форматированный JSON помещает в раскрывающийся блок.

История хранится только в открытой вкладке и сбрасывается после обновления страницы.
