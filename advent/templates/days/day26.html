Практика

Модель на своём маке

Двадцать пять дней модель жила в облаке: запрос уходил в DeepSeek, ответ приходил обратно, за каждый токен платили. Сегодня модель запускается прямо на маке: Ollama держит её в памяти и отвечает на localhost — без ключа, без интернета, данные никуда не уходят. Цена — скорость и качество теперь зависят от нашего железа.

Пока просто можно дёрнуть и проверить в любом клиенте.

Алексей Гладков, 5.10 — на вопрос, надо ли сразу подключать локальную модель к своему приложению
  1. 01

    Запуск

    Ollama — сервер на маке: скачивает модель, держит её в памяти и отвечает на localhost:11434. Модель выбираем под железо — она должна целиком влезть в память.

    ollama pull · ollama serve

  2. 02

    CLI и HTTP API

    Два способа спросить: из терминала командой ollama run и по HTTP — запросом с сообщениями, почти как к облачному API. Второй нужен, чтобы подключить модель к приложению.

    ollama run · POST /api/chat

  3. 03

    Три запроса

    Простой, средний и сложный: факт, рассуждение, задача посложнее. Смотрим не только на ответ, но и на время, скорость в токенах в секунду и прогрев модели.

    просто · средне · сложно

  4. 04

    Без облака

    Нет ключа, нет счёта за токены, работает без интернета, данные остаются на машине. Взамен — скорость и ум модели ограничены памятью и чипом.

    localhost, без ключа
