День 22.
Первый RAG-запрос

Домашнее задание

Реализуйте функцию: вопрос → поиск релевантных чанков → объединение с вопросом → запрос к LLM.

  • Сравните ответ модели без RAG и ответ модели с RAG.
  • Усиление: составьте мини-набор из 10 контрольных вопросов по вашей базе.
  • Усиление: для каждого вопроса зафиксируйте ожидание (что должно быть в ответе) и какие источники должны быть использованы (если применимо).
Ожидаемый результат
Агент с двумя режимами (с RAG / без RAG) + 10 контрольных вопросов и сравнение качества.
Формат
Видео + код

Практика

Сначала найти, потом ответить

Вчера построили индекс по нашему проекту. Сегодня он начинает работать: по вопросу находятся ближайшие куски, они вместе с вопросом уходят модели — и та отвечает по нашим документам, а не по памяти. Тот же вопрос уходит и без кусков, чтобы разница была видна рядом.

Так сделать запрос с рагом и сделать без него.

А, ну это типа задача со звёздочкой.

Алексей Гладков, 29.09 — что показать на видео и что значит блок «Усиление»
  1. 01

    Поиск

    Вопрос превращается в вектор той же моделью, что и база, и индекс дня 21 отдаёт несколько ближайших кусков — с файлом, разделом и строками.

    вопрос → top-K кусков

  2. 02

    Промпт

    Найденные куски склеиваются с вопросом в один запрос: «отвечай по этим фрагментам и назови, откуда взял». Если в них ответа нет — так и сказать.

    куски + вопрос → LLM

  3. 03

    Два режима

    Одна модель, один вопрос, два запроса: без базы — только по памяти модели, с базой — по найденным кускам. Ответы стоят рядом.

    без RAG · с RAG

  4. 04

    Контрольные вопросы

    Десять вопросов по проекту, у каждого — что должно быть в ответе и из каких файлов. Прогон показывает, какой режим попал, а какой нет.

    ожидание + источники → сверка
