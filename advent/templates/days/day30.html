Практика

Своя модель — для других людей

Всю неделю gpt-oss отвечала только нам: Ollama слушает localhost, и снаружи к ней не достучаться. Сегодня мак становится домашним сервером. Наружу выходит не сама Ollama, а наша обёртка: она проверяет ключ, ставит запросы в очередь и следит за лимитами. Через неё к модели можно обратиться из интернета — по HTTP API или из чата с телефона.

Нужно здесь проверить клиент сервер. Да, нужно сэмулировать хотя бы два коннекта условно. Желательно с двух устройств.

Значит надо сделать обвязку. Какую-нибудь очередь повесить.

Рекомендую все же сделать доступным именно в интернет.

Алексей Гладков, 9–10.10 — что проверять в задании: Ollama считает один ответ за раз, поэтому нужна очередь; адрес — из интернета, не только из домашней сети
  1. 01

    Сервис на маке

    Мак — домашний сервер: на нём модель и наше HTTP API. Ollama по-прежнему слушает только localhost, к ней обращается одна обёртка.

    клиент → API → Ollama

  2. 02

    Доступ из интернета

    Туннель даёт маку публичный https-адрес без белого IP и настройки роутера. Без ключа сервис не отвечает.

    https-адрес · ключ доступа

  3. 03

    Очередь

    Модель на маке одна и считает один ответ за раз. Остальные запросы ждут своей очереди и знают своё место в ней — ничего не падает.

    два устройства · одна модель

  4. 04

    Ограничения

    Rate limit — сколько запросов в минуту можно одному ключу. Max context — сколько текста можно прислать за раз. Лишнее получает понятный отказ.

    rate limit · max context

Сервис · что где работает

наружу — только обёртка, Ollama остаётся на localhost
