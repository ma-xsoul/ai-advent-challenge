Состояние задачи

Домашнее задание

Реализуйте состояние задачи как конечный автомат (Task State Machine).

  • У задачи есть этап, текущий шаг и ожидаемое действие.
  • Пример состояний: planning → execution → validation → done.
  • Проверьте паузу на любом этапе.
  • Проверьте продолжение без повторных объяснений.

Практика

Задача — это объект, а не разговор

До сих пор задача жила только в голове пользователя и в стеке сообщений. Теперь она — отдельная сущность с формальным состоянием: на каком этапе, какой шаг внутри этапа, чего ждём дальше. Задача рождается с первой репликой, двигается по этапам, и её можно поставить на паузу и продолжить без пересказа.

  1. 01

    planning

    Уточнить, что нужно, и собрать план. Выход — согласованный список шагов.

    ждём: план утверждён

  2. 02

    execution

    Идти по шагам плана по одному. Выход — результат каждого шага.

    ждём: шаг сделан

  3. 03

    validation

    Проверить результат против плана и требований. Выход — принято или возврат на шаг.

    ждём: проверка пройдена

  4. 04

    done

    Задача закрыта. Состояние остаётся, чтобы к нему можно было вернуться.

    ждём: ничего
