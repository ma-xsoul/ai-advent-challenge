Домашнее задание

Используйте RAG для подключения к документации вашего проекта:

  • README
  • project/docs
  • схемы данных или API-описания

Через MCP подключите ассистента к проекту:

  • минимум — получение текущей git-ветки
  • по желанию — список файлов или diff

Реализуйте команду:

  • /help — ассистент отвечает на вопросы о проекте
  • использует документацию и контекст проекта

Минимальный результат:

  • README + папка docs в RAG
  • MCP — хотя бы git branch
  • /help отвечает на вопросы о структуре проекта
Ожидаемый результат
Ассистент разработчика, понимающий проект.

Практика

Ассистент, который знает наш проект

Неделя 8 — последняя: собираем всё, что умеем, в рабочие инструменты. Первый — ассистент разработчика для этого же проекта. RAG знает README, docs и код — свежий индекс проекта, собранный тем же кодом, что в дне 21. MCP-сервер видит git: текущую ветку, изменённые файлы, diff. Команда /help отвечает на вопросы о проекте с источниками и с учётом того, над чем идёт работа прямо сейчас.

Под проектом подразумевается любой проект с документацией. На этой неделе мы учимся гонять наш сетап и всё, что мы умеем, в более-менее реальных условиях.

Отступление от задания тут норм, главное соединить RAG и MCP и дать юзерам команды подёргать.

RAG для документации, MCP для гита, ядро — агент.

Алексей Гладков, 13 и 16.10 — что считать проектом и как устроить ассистента
  1. 01

    RAG по документации

    README, docs и код проекта — свежий индекс в data/day31 с векторами bge-m3. Ответ опирается на найденные куски и ссылается на них.

    README · docs · код

  2. 02

    MCP для git

    Свой MCP-сервер над репозиторием: текущая ветка, изменённые файлы, diff. Ассистент видит, над чем идёт работа сейчас.

    git branch · status · diff

  3. 03

    Ядро — агент

    Агент сам решает, что ему нужно: поискать в документации, спросить git или и то и другое — и собирает ответ.

    агент = RAG + MCP

  4. 04

    Команды

    /help — вопрос о проекте и его структуре. Короткие команды — ветка и изменения без модели, прямо из git.

    /help · /branch · /diff
